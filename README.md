# Hi, I'm Ana Luiza 👋

I design machine learning problems hard enough to stump state-of-the-art coding agents, and I build the expert solutions they fail to reach.

### What I do
- Design advanced ML problems in specialized domains, with naive-to-gradient-boosted baselines to calibrate difficulty and expert reference solutions that beat them
- Author deterministic scoring functions for RL feedback, with safeguards against reward hacking
- Review AI-generated code across Python, TypeScript, JavaScript, and Lua, and find failure modes through multi-turn adversarial probing
- Write golden specifications and weighted rubrics for evaluating generated code and games

### Game development
I write Lua for Roblox, from bug fixes to feature implementations, and design evaluation tasks for AI agents working on game codebases, where "it compiles" is rarely the same as "it plays right." I also author the reference specs and scoring rubrics those evaluations grade against, and review other annotators' work against them.
